# Original Ctrl Z city art

Current overhaul sources: `city_architecture.py` draws the ten general city models; `infrastructure_art.py` draws the six facility identities; `lantern_art.py` draws the three initial Lantern models/court; `light_art.py` bakes architectural illumination; `street_art.py` draws paired street/court masks. Run `python -B scripts/build-city-art.py` to rebuild committed assets. None contains purchased sprites, public-preview pixels or external fonts. Antahonist Neon City is visual guidance, with pixel-city-reference-2.png secondary.

The city atlas is 2048×1536 (~168 kB PNG); the shared paired street atlas is 2048×2048 (~117 kB PNG). Sixteen road-edge masks have powered/unpowered variants. `streetPlan.json` is the shared runtime street truth for world/minimap; `chunkRoadMask` selects the matching ground frame. The separate Lantern court variant and all building sprites retain the original projection/pivots. Lighting switches through retained textures, not per-frame filters or animation.

Lantern Yard adds three original models and `lantern-yard.png`, authored in `scripts/lantern_art.py` and built by the same generator. These use the existing atlas/pivot/projection, 24-pixel floor modules, street-facing entrances, a stepped apartment roof, low café roof and paved court. They are original project art inspired by Antahonist's architectural principles, not purchased kit sprites. The ground variant covers only the existing Lantern Yard block; roads and crossings retain the shared world alignment.

city-atlas.png and street-tile.png are original, locally authored project assets generated by scripts/build-city-art.py. No reference pixels, external fonts, downloaded textures or generated-image assets are embedded. The reference images remain design guidance only.

Rebuild: install Pillow in your Python environment, then run `python scripts/build-city-art.py`. Normal Node builds use the committed PNGs and generated cityModels.ts; Python is not required for players or CI. Projection is 39:20 world pixels. Building frames are 256x256 with origin (128,140), powered/unpowered pairs; the 400x224 ground texture has origin (200,12) and exactly covers one five-tile block. Pixel sampling is nearest-neighbor. Update model metadata and geometry together when changing silhouettes.

Architecture includes original bitmap sign lettering, recessed glazing, awnings, external stairs, parapets, ventilation equipment, service roofs and street props. This remains a modular vocabulary, not an exact reproduction of the primary reference or a claim that bespoke art refinement is finished.
