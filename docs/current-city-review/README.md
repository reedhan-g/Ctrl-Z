# Rendered city overhaul evidence

Captured from the actual Pixi game in Chromium desktop/mobile emulation after the city-wide artwork, shared streets, infrastructure, lighting and camera milestones. These deliberately selected review images are source review artifacts; disposable full test captures stay ignored.

- `desktop-opening.png` and `mobile-opening.png`: the default view, without manually navigating to the earlier remote exemplar.
- `intersection.png`: authored central-city streets and six recognizable service designs.
- `hospital.png` and `mobile-hospital.png`: selection and roof/panel clearance.
- `lantern-north.png` and `lantern-south.png`: two normal exploration views covering the authored four-block neighborhood; the existing finite camera cannot frame the full edge neighborhood at a wide zoom without clamping.

Primary visual comparison: [Neon City by Antahonist](https://antahonist.itch.io/neon-city-cyberpunk-pixel-building-kit), whose public banner was inspected alongside these renders. Original Ctrl Z raster/code assets adopt dark teal mass, consistent floor modules, stepped roofs and controlled cyan/warm/magenta light. No preview pixels or purchased sprites are embedded. `design/pixel-city-reference-2.png` remains secondary inspiration.

73 unit checks, all 50 browser specifications and production build pass; final presentation polish received additional focused checks. The browser review also captures each infrastructure facility and all four map edges in ignored test output. Physical-device performance/Safari and creator visual acceptance are still pending. Texture-size and performance limitations are in DEVELOPMENT_STATUS.md.
