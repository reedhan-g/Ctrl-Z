# Ctrl Z — project brief

## Concept
Delete one critical system from reality. Explore its cascading effects across a miniature city, inspect dependencies, intervene, and rewind to compare outcomes. Use the name **Ctrl Z**, without a plus sign.

## Art direction
Dark navy/charcoal nighttime isometric city. Muted cyan and teal systems, amber windows, coral disruption warnings. Compact, restrained interface surrounding a detailed miniature city. The implementation uses authored procedural vector geometry, not generated concept-art backgrounds.

## Milestone 1 — implemented, runtime verification blocked
Four buildings, electricity outage, draining reserves, water dependency cascade, intervention supplies, undo, time controls, dependency view, camera controls, desktop and mobile layouts. React, TypeScript, Vite, PixiJS and Zustand.

## Next development steps
1. Restore npm registry access, install dependencies and run build + desktop/mobile browser specifications. Review the rendered scene against the user's original reference and refine the art.
2. Add richer time-indexed event history and branching replay that preserves earlier interventions.
3. Expand traffic, deliveries and interconnected building effects.
4. Add separate Internet, GPS and digital-payment experiments.

The later steps are an implementation proposal, not a recovered authoritative roadmap. The first milestone follows the retrieved project decisions.
